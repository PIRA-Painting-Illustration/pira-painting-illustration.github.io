# pira-art.com

The website and guide for [PIRA](https://github.com/PIRA-Painting-Illustration/PIRA), a free painting app for pen tablets.

This repository only hosts the built site. Its source is in PIRA's
[`web/landing`](https://github.com/PIRA-Painting-Illustration/PIRA/tree/main/web/landing) and
[`docs/wiki`](https://github.com/PIRA-Painting-Illustration/PIRA/tree/main/docs/wiki). Please send
changes and report problems there.

Credits: PIRA is built on [PhotoCraft](https://github.com/storytold/photocraft) by ArtCraft. The
screenshot photo is by Filippo Molinari on Unsplash. Pose data is from
[mocap.cs.cmu.edu](http://mocap.cs.cmu.edu).
